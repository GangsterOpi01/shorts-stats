Privacy Policy

Shorts Stats · last updated 25 November 2026

Shorts Stats is a private tool that reads the statistics of the owner's own YouTube channels. Its only user is the owner of those channels.

Data the tool accesses

Through the YouTube API Services the tool requests two read-only permissions from the channel owner's Google account: youtube.readonly (the channel's own video list, titles and public counts) and yt-analytics.readonly (YouTube Analytics reports of the channel's own videos, such as views, watch time, average view percentage, likes, subscribers gained, traffic sources and audience retention). It cannot upload, post, comment, edit or delete anything.

Storage

The access token and the downloaded reports are stored only on the channel owner's own computers. They are used only to judge which of the owner's videos work well. Nothing is sent to any server other than Google's. No data is sold, shared with third parties or used for advertising.

Other people's data

The tool only reads aggregated channel and video statistics. It does not collect, store or process personal data about viewers or any other YouTube users.

YouTube and Google

Shorts Stats uses YouTube API Services. By using it you agree to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions. Revoking it makes the stored token invalid immediately. On request, all locally stored data is deleted within 7 days.

Datenschutzerklärung

Shorts Stats ist ein privates Werkzeug, das die Statistik der eigenen YouTube-Kanäle des Betreibers liest. Es wird ausschließlich vom Kanalinhaber genutzt.

Über die YouTube API Services fragt es zwei reine Leserechte an: die eigenen Kanal- und Videodaten (youtube.readonly) und die YouTube-Analytics-Berichte der eigenen Videos (yt-analytics.readonly), etwa Aufrufe, Wiedergabezeit, Zuschauerbindung und Zugriffsquellen. Hochladen, Posten, Kommentieren, Ändern oder Löschen ist damit nicht möglich.

Zugangsschlüssel und Berichte liegen nur auf den eigenen Rechnern des Kanalinhabers. Daten gehen an keinen Server außer an den von Google. Es werden keine Daten verkauft, an Dritte weitergegeben oder für Werbung genutzt, und es werden keine personenbezogenen Daten über Zuschauer oder andere Nutzer erhoben.

Es gelten die Nutzungsbedingungen von YouTube und die Datenschutzerklärung von Google. Den Zugriff kann man jederzeit unter myaccount.google.com/permissions widerrufen. Auf Anfrage werden alle lokal gespeicherten Daten innerhalb von 7 Tagen gelöscht.
