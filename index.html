Shorts Stats

Shorts Stats is a private tool used by one YouTube creator for their own channels. It reads the statistics of the creator's own videos (views, watch time, audience retention, traffic sources) so the creator can see which stories work and plan the next videos.

The tool only reads. It cannot upload, post, comment, edit or delete anything. It is not offered to the public: only the channel owner signs in, and it never accesses other people's accounts or data.

Deutsch: Shorts Stats ist ein privates Werkzeug eines YouTube-Creators für seine eigenen Kanäle.
